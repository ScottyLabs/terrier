Terrier is a hackathon management platform. These docs cover development and the API.

- [API routes and policies](/guides/api-routes/): add a route with its access checks, tests, and docs.
- [Frontend development](/guides/frontend/): work on the Svelte app and use the API client.
- [Authentication](/guides/authentication/): configure sign-in and sessions.
- [Database](/guides/database/): find tables, write queries, and add migrations.
- [Authorization policies](/reference/policies/): find permission rules and policy outputs.
- [API errors](/reference/api-errors/): choose an error and handle its response.

See the [repository](https://git.cmu.dev/ScottyLabs/terrier) for source code,
contributor instructions, and RFCs. Endpoint documentation is in the API sidebar.
